# Artem Marshal — локальный сайт

Русскоязычный полноэкранный каталог украшений в виде интерактивного рабочего стола. Исходники и материалы остаются локально в проекте; сайт не публиковался.

## Запуск

Откройте `index.html` в браузере или используйте `Открыть сайт.command`.

## Каталог и карточки

- В каталоге оставлены только украшения и запрос на кастом; файлы одежды на диске не удалялись.
- Иконки колец крупнее и кадрированы так, чтобы не обрезать изделие. На широком экране плотный каталог перестраивается в прокручиваемую сетку: плитки можно перетаскивать для перестановки, порядок хранится локально. На телефоне сохраняется постраничный вид.
- В карточке показывается один снимок изделия во всю доступную область; его кадрирование удаляет лишние пустые поля, оставляя безопасный отступ вокруг целого украшения. Стрелки и точки переключают остальные кадры. Нажатие открывает полноэкранный просмотр: снимок центрируется и вписывается в свободную центральную область между панелью и контролами, с масштабом кнопками/колесом/щипком и перетаскиванием увеличенного изображения.
- Видео есть у всех 28 моделей. Шесть роликов сохранены локально с нативными элементами управления; оставшиеся 22 ролика показываются официальными Telegram-встраиваниями из 21 точного поста (пост моделей 21/22 содержит оба ролика). Для воспроизведения встроенных роликов нужно подключение к интернету; напрямую в `dist/` их копии не помещаются. Воспроизведение начинается по действию пользователя.
- Фото модели 17 дополнено чистым белым внутренним проёмом; исходный файл сохранён в `assets/marshall/jewelry/`. Кадры карточек находятся в `assets/marshall/product-display-tight/`; кадрирование не перезаписывает исходники. Новая обложка кастомного заказа и цветочная эмблема из папки пользовательских правок включены в локальные активы.
- Для выбранных фотографий подготовлены отдельные ретушированные варианты в `assets/marshall/enhanced-jewelry/retouched/`, включая модели 21–22 и 28. Исходные фото сохранены; пустые проёмы скорректированы с сохранением контура и фактуры. Все кадры карточек в `assets/marshall/product-display/` центрированы на квадратном холсте с равным масштабом по габаритной стороне — кольцо не обрезается.
- В карточки перенесены описания из 23 подтверждённых публикаций `@marshaljew`; каждая такая карточка ведёт на конкретный пост. Для моделей без отдельного текста в посте или без подтверждённого совпадения описание оставлено пустым. Сверка источников: [Источники-описаний.md](Источники-описаний.md).
- В шапке отображаются цветочная эмблема и правильное написание **Artem Marshal**. Фоновое видео на ПК показано тремя вертикальными панелями в ряд, чтобы сохранить портретную композицию роликов; на телефоне ролики последовательно сменяют друг друга. Видео запускаются без звука. При `prefers-reduced-motion` cross-fade отключается, но явно запрошенное видео продолжает играть.

## Музыка и связи

Локальные аудиодорожки и ссылки VK / SoundCloud сохранены в музыкальном окне с отдельными иконками платформ. Ссылка на Telegram из музыкального окна убрана; канал колец [@marshaljew](https://t.me/marshaljew) остаётся отдельной кнопкой в Dock. Вопросы по изделиям можно направить автору [@coldnixen](https://t.me/coldnixen).

## Корзина

Корзина сохраняется локально в браузере, позволяет менять количество и подготовить заявку с текстом для Telegram. Сайт не принимает оплату и не отправляет заявку автоматически: перед отправкой пользователь проверяет сообщение, а автор подтверждает цену, наличие, размер и сроки.

Подробное техническое задание и критерии приёмки: [ТЗ-обновление-сайта.md](ТЗ-обновление-сайта.md). Источники описаний изделий: [Источники-описаний.md](Источники-описаний.md).

## Подготовка к публикации

Выполните `sh build.sh`; для release-сборки установленный `ffmpeg` должен включать кодеки `libx264` и `libmp3lame`. Скрипт перекодирует только копии в `dist/`: шесть локальных товарных видео остаются MP4/H.264, три фоновых ролика кодируются в портретном разрешении без аудио, звук в музыкальном окне — MP3 160 кбит/с. Исходные медиа не меняются. Сборка включает сайт, маршрутный манифест, актуальные изображения, постеры фоновых видео, обложку кастома, цветочный знак и аудиодорожки. Остальные товарные видео загружаются официальным Telegram-виджетом из публичных постов, поэтому для них нужно интернет-соединение.

Сайт не требует Node.js, собственного серверного API или базы данных. Для публикации загрузите содержимое `dist/` в корень выбранного статического хостинга. У Vercel Hobby ограничение на объём исходных файлов, загружаемых через CLI, составляет 100 МБ, поэтому сборка прекращается, если пакет больше 90 МБ; актуальную формулировку смотрите в [документации Vercel Limits](https://vercel.com/docs/limits). Перед выпуском укажите реальный домен, проверьте доменные записи/HTTPS и воспроизведение локальных и встроенных медиа с опубликованного адреса.

## Добавление новых изделий и фото

Сейчас каталог находится в массиве `jewelryProducts` в `script.js`. Новую запись нужно добавить туда, подготовить display-кадры в `assets/marshall/product-display-tight/` и положить оригиналы фото в `assets/marshall/product-display/`; в `images` укажите все ракурсы, в `image` — главный, а `alt` заполните описанием. Иконки лежат в `assets/jewelry-icons/`. Затем выполните `sh build.sh` и загрузите обновлённый `dist/`.

Если фотографии будут обновляться часто и без разработчика, оптимальный следующий шаг — Sanity Studio как отдельная авторизованная CMS: фото и поля товара редактируются в браузере, сайт получает оттуда только опубликованный каталог. Это потребует отдельной интеграции каталога с CMS, но не придётся вручную менять `script.js`. Более лёгкая git-based админка подходит, если пользователь готов работать с репозиторием и каждый раз запускать новую сборку.
