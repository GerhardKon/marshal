# Финальная проверка Artem Marshall

**Дата:** 13 октября 2026 г.  
**Статус:** локальная production-сборка создана; публикация на сервер не выполнялась.

## Готовый пакет

Сборка `sh build.sh` создаёт чистую папку `dist/` и перекодирует только её копии медиа. Исходные фотографии, видео и музыка остаются нетронутыми. Итоговая папка занимает около **80,7 МБ**, а ZIP-архив — **80,1 МБ**. Архив проверен на целостность; в корне архива лежат `index.html`, стили, JavaScript и все необходимые активы, поэтому его содержимое можно распаковать прямо в корень сайта.

Это оставляет запас относительно лимита **100 МБ** для статических файлов, загружаемых через CLI на Vercel Hobby. Важно отправлять только `dist/` или ZIP этого каталога, а не весь проект с исходными медиа и рабочими файлами. [1]

## Что проверено

- **28 уникальных записей** каталога: 27 изделий и одна пользовательская позиция для корзины; одежды и её активных CSS-селекторов в runtime-коде нет.
- Все пути из HTML, CSS и JS разрешаются в релизной папке; повторяющихся HTML ID и пустых файлов не обнаружено.
- Синтаксис `script.js` и `photo-gallery.js` проходит `node --check`; блоки CSS сбалансированы.
- Все шесть локальных товарных роликов и пять музыкальных дорожек читаются через `ffprobe`. Ролики остаются MP4/H.264 с исходным вертикальным разрешением; звук каталога в ZIP сохранён в MP3 160 кбит/с.
- У внешних ссылок с новой вкладкой есть `noopener`; у шести HTML-иконок задан `alt=""` намеренно, поскольку это декоративные изображения внутри кнопок с собственными доступными названиями.
- Маршрутный манифест теперь содержит английское имя **Artem Marshall**.
- После замечания по телефону исправлено вращение фоновых колец: анимация больше не схлопывается при системной настройке уменьшения движения; на мобильной ширине для трёх колец заданы более заметные отдельные скорости. Версия CSS обновлена для сброса кэша.

Проверка была статической: она подтвердила структуру и читаемость медиа, но не заменяет отдельный визуальный прогон опубликованной версии в браузерах и на телефонах. Перед публичным запуском проверьте фактический адрес, HTTPS, размеры фото/видео на мобильном устройстве и воспроизведение медиа уже с хостинга.

## Добавление новых фото сейчас

Каталог хранится в массиве `jewelryProducts` файла `script.js`. Для нового изделия нужно добавить запись, положить оригиналы фото в `assets/marshall/product-display/`, заполнить `images`, `image` и текст `alt`, затем выполнить `sh build.sh` и загрузить обновлённый `dist/`. Поля и структура записей описаны в [README проекта](../README.md).

## Какую админку выбрать

**Моя рекомендация для будущего — Sanity Studio.** В нём можно сделать форму товара с названием, ценой, главным фото, дополнительными ракурсами, описанием, ссылкой на пост Telegram и необязательным видео. Редактор сможет загружать изображения и менять опубликованные записи через веб-интерфейс; файлы и каталог хранятся отдельно от кода сайта. Это потребует отдельной интеграции в текущую статическую страницу — самой админки в этом релизе ещё нет. Sanity предоставляет Studio и API для управления медиа; изображения можно преобразовывать при выдаче. [2] [3]

Для редких обновлений дешевле по сложности оставить нынешний процесс с правкой `script.js`. Git-based CMS — промежуточный вариант: она удобнее ручного редактирования кода, но всё равно сохраняет контент в репозитории и запускает новую сборку после публикации. В любой CMS секрет для записи нельзя помещать в клиентский JavaScript.

## Границы публикации

Сайт остаётся локальным, как и было указано. В рабочей папке нет Git-репозитория или конфигурации хостинга, поэтому здесь не было обновления удалённой версии, настройки домена или фактической загрузки на Vercel/другой сервер.
